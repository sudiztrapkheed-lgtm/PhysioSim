# PhysioSim

An independent computational project exploring how selected
physiological signals respond to a hypothetical blood-loss
disturbance over time.

## Features

- Interactive physiological simulation
- Heart rate modelling
- Systolic and diastolic blood pressure modelling
- Oxygen saturation visualization
- Adjustable simulation parameters
- Mathematical methodology and scientific references

## Technologies

- Python
- Streamlit
- NumPy
- Pandas
- Plotly

## Running locally

Install dependencies:

    pip install -r requirements.txt

Launch the application:

    python -m streamlit run app.py

## Scientific limitations

PhysioSim is an educational conceptual model.
Its equations and parameters are illustrative and have not
been clinically calibrated or validated.
It is not a diagnostic or treatment tool.
